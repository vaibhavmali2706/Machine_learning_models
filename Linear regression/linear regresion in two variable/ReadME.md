# 📈 Two-Variable Linear Regression

A Machine Learning project that implements **Multiple Linear Regression** using Python and Scikit-learn to predict house prices based on multiple features.

## 📌 Overview

This project demonstrates how Multiple Linear Regression can be used to predict the price of a house using:

- 🏠 Square Feet
- 🚪 Number of Rooms
- 📅 Age of the House

The target variable is:

- 💰 Price in Lakhs

The model learns the relationship between the input features and house price and can then be used to predict prices for new houses.
