# Linear Regression - Single Variable

## Objective

Predict house prices based on the area of the house in square feet.

## Dataset

The dataset contains:

- Square_Feet - Area of the house
- Price_Lakhs - House price in lakhs

## Machine Learning Algorithm

Linear Regression

## Feature

Square_Feet

## Target

Price_Lakhs

## Workflow

1. Create the dataset using Pandas
2. Separate feature and target
3. Visualize the data
4. Create Linear Regression model
5. Train the model using `fit()`
6. Make predictions using `predict()`
7. Visualize the regression line

## Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Model

The model learns the relationship:

Price = m × Square_Feet + c
